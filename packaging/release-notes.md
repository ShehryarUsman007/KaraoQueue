A very basic karaoke singer rotation app, made for a karaoke group in Windsor, Ontario. Nothing else needs to be installed: .NET is bundled with every download.

### Which file do I download?

| System | File |
|---|---|
| **Windows** 10/11 | `KaraokeShuffler-…-Setup.exe` (installer; no admin rights needed) |
| **Ubuntu / Debian / Mint** | `karaoke-shuffler_…_amd64.deb` |
| **Fedora / openSUSE / RHEL** | `karaoke-shuffler-…x86_64.rpm` |
| **Any other Linux** | `KaraokeShuffler-…-x86_64.AppImage` (make it executable, then run it; no install) |
| **Mac with Apple chip** (M1–M4) | `KaraokeShuffler-…-macOS-AppleSilicon.zip` |
| **Mac with Intel chip** | `KaraokeShuffler-…-macOS-Intel.zip` |

### Mac: first launch

The Mac version isn't signed by Apple, so macOS blocks it the first time:

1. Unzip it and drag **Karaoke Shuffler** into **Applications**.
2. Open it once. When macOS says it can't be verified, click **Done**.
3. Go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Karaoke Shuffler.

After that it opens normally. (On macOS 14 and older you can also right-click the app → **Open**.)

### Windows: SmartScreen

Windows may show "Windows protected your PC" because the installer isn't signed. Click **More info → Run anyway**.
